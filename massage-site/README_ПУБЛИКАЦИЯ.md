## Поддомен

## Статус
**Готовый технический прототип для согласования. В интернете пока НЕ размещён.**
Исходных необработанных фотографий сотрудников в созданных папках Google Диска пока нет, поэтому три портрета для прототипа выполнены как кадрирование (без генерации лиц) из предоставленных готовых постеров. Перед публичным запуском рекомендуется заменить их подтверждёнными фотооригиналами.

## Состав
- `/index.html` — главная страница, специалистами и прайсами.
- `/specialists/svetlana/`, `/specialists/anna/`, `/specialists/grigory/` — персональные страницы.
- `/assets/` — изображения и неизменённые оригинальные логотипы клуба.
- `/content.json` — единый источник данных для дальнейших обновлений (после редактирования необходимо пересобрать HTML).
- `styles.css`, `app.js`, `404.html`, `robots.txt`, `sitemap.xml`, `CNAME`.

## Сборка и публикация на хостинге
Сайт полностью статический, не требует PHP/Node.js/базы данных и форм обработки персональных данных. Для публикации:
1. В панели хостинга добавить сайт/домен `massage.liniyasporta.ru`, указать отдельную корневую папку для него.
2. Распаковать архив и разместить **содержимое** этой папки в корневом каталоге поддомена, сохранив структуру `/assets/`, `/specialists/`.
3. В панели DNS домена `liniyasporta.ru` создать запись для имени `massage` (A/AAAA — IP хостинга; CNAME — если хостинг предоставил доменное имя), без выдуманного IP. На хостинге включить SSL, HTTPS и редирект HTTP→HTTPS.
4. Проверить доступность всех страниц и телефонные ссылки на мобильном телефоне.
5. После утверждения цен и фотографий выполнить финальный QA и затем подключить поддомен к Яндекс.Вебмастеру, если необходимо.

Важно: подстановка DNS записи, SSL и загрузка на веб-хостинг **не выполнены** без доступа к панели REG.RU/хостинга. Наличие файла `CNAME` не создаёт DNS автоматически.
