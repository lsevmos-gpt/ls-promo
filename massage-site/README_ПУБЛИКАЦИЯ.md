## Файлы
- `index.html` — главная с тремя специалистами в последовательности Анна → Григорий → Светлана Щетинина.
- `specialists/*/index.html` — три самостоятельные страницы и полный прайс.

- `assets/` — исходные MASTER-логотипы без изменения файлов и временные портреты (кадрирования из утверждённых постеров).
- `content.json` — исходные сведения для актуализации. При изменении JSON статический HTML нужно обновить тоже.

## Важные факты до запуска
1. Светлана принимает **только по воскресеньям**.
2. Прайс Анны на текущем макете обозначен «предварительным». Источник: `Линия_спорта_ФИТНЕС_прайс_массаж_А4.pdf`; **имени Анны на нём нет**. Уточнить принадлежность и актуальность всего прайса перед публикацией, включая аппаратные процедуры и абонементы. Цены не показываются как подтверждённые.
3. Григорий и Светлана — цены взяты с присланных постеров, не подменены ценами Анны.
4. Изначально предоставленные портреты — кадрированные готовые постеры. **Не первичные фотоснимки**. Перед публикацией нужны реальные фото с оригинальным разрешением из Google Диска.
5. Сайт не содержит форм сбора персональных данных, только `tel:`-ссылки.
6. Пользователь подтвердил поддомен, но DNS/SSL и хостинг могут быть не настроены. Не публиковать автоматически до проверки.
