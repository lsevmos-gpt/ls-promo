# Меню спортбара «Линия спорта»

Публичный сайт: `bar-site/`; целевой адрес: https://bar.liniyasporta.ru/.

Меню перенесено из фотографии владельца от 29.10.2026. По уточнению 30.10.2026 «Хорнет» заменён на «Бамбл-кофе» с карамельным сиропом, цена 300 ₽ сохранена. Всего 22 позиции и 6 разделов. Выбора клубов нет.

`build_menu.py` пересчитывает menu.json из состава и расчётных порций. `render_site.py` обновляет статическую страницу. Значения КБЖУ — предварительные: граммовки не являются подтверждённой технологической картой клуба. Для пяти позиций численные данные не выдуманы.

Исходные значения USDA сохранены в reference-foods.json; этикетки аналогов и их URL — в menu.json. Марки фактического спортпита клуба не подтверждены. Все изображения — AI-визуализации, не фотографии реальной подачи.

home-block.html — блок для главной страницы; подключается после раздела services. Действующие цены клубных карт и тренерские абонементы не изменяются.
