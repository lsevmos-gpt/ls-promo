# Меню спортбара «Линия спорта»

Публичный сайт: `bar-site/`; целевой адрес: https://bar.liniyasporta.ru/.

Меню перенесено из фотографии владельца от 29.10.2026. По уточнению 30.10.2026 «Хорнет» заменён на «Бамбл-кофе» с карамельным сиропом, цена 300 ₽ сохранена. Всего 21 позиция и 5 разделов. Протеиновые батончики исключены: это товары магазина, а не приготовляемые позиции бара. Выбора клубов нет.

`build_menu.py` пересчитывает menu.json из состава и расчётных порций. `render_site.py` обновляет статическую страницу. Значения КБЖУ — предварительные: граммовки не являются подтверждённой технологической картой клуба. Для четырёх позиций численные данные не выдуманы.

Исходные значения USDA сохранены в reference-foods.json; этикетки аналогов и их URL — в menu.json. Марки фактического спортпита клуба не подтверждены. Фотографии меню — AI-визуализации состава и подачи. Для каждой из 21 позиции используется отдельное изображение. Видео взяты из папки «Бар» владельца на Google Диске; ссылки и параметры оптимизации — в media-sources.json.

home-block.html — блок для главной страницы; подключается после раздела services. Действующие цены клубных карт и тренерские абонементы не изменяются.

Бамбл-кофе находится в разделе «Напитки». На телефоне закреплён выбор раздела меню; фотографии не обрезаются. Короткие видео загружаются по видимости или по кнопке, одновременно играет одно без звука; учтены экономия трафика и reduced motion. Цены и расчёты КБЖУ для всех 21 оставшейся позиции сохранены.

Обновление 30.10.2026: в спортивном питании креатин заменяет L-карнитин. Цена 130 ₽ сохранена с прежней позиции и требует подтверждения. КБЖУ креатина уточняются по этикетке. Вместо неудачной векторной иллюстрации установлена реалистичная светлая фотография в стиле остальных карточек меню: стакан воды и мерная ложка порошка без брендов и надписей.
Фото креатина утверждено владельцем 30.10.2026: безо льда, с отдельным солнечным фоном, высоким стаканом и мерной ложкой. Файл `bar-site/assets/creatine-approved-20261030.jpg`.
