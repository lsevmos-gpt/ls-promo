# app.liniyasporta.ru — сайт мобильного приложения

Папка `app-site/` относится только к https://app.liniyasporta.ru/. Основной сайт клуба находится в `new-site/`, сайт акций — в `promo-site/`.

## Выбранное оформление — 29.10.2026

Владелец выбрал первый вариант кнопок: графитовый App Store (#303936) со светлой окантовкой (#708377), белый Google Play с цветным логотипом, синий RuStore с оригинальным белым знаком. Сохранены подписи iPhone/Android и стрелки из согласованного образца. Все три исходные ссылки магазинов и исходное изображение телефона сохранены. Файл index.html самодостаточный: стили и графика включены в него.

Вёрстка проверена в браузере при ширине 320, 390, 768, 1251, 1363 и 1500 px. Названия и стрелки помещаются, кнопки одинаковой высоты. Для узких экранов кнопки располагаются одна под другой.

## Подключение публикации

Сценарий: `.github/workflows/deploy-app-reg.yml`.

В Settings → Secrets and variables → Actions этого репозитория нужны:

- Repository variable `APP_REG_USER`: логин FTP-пользователя, корень которого соответствует именно app.liniyasporta.ru.
- Repository secret `APP_REG_PASSWORD`: пароль этого FTP-пользователя. Пароли в исходники и сообщения не добавляются.

Хост: server169.hosting.reg.ru, explicit FTPS, порт 21, путь внутри FTP-сессии `/`. Учётные записи других доменов для публикации не используются.

После добавления настроек запустить Actions → Deploy app.liniyasporta.ru to REG.RU → Run workflow → main. Изменения app-site/ в main также запускают этот сценарий.

Перед записью index.html, полученный по FTP, должен побайтно совпасть с ожидаемым исходным сайтом и текущей HTTPS-страницей app.liniyasporta.ru. До замены сохраняется резервная копия в артефакт запуска. Загрузка идёт во временный файл с последующим переименованием; остальные файлы не удаляются. Успех подтверждается точным совпадением опубликованного HTML.

`deployment.json` хранит контрольную сумму предыдущей публичной страницы и одобренного нового index.html. Для следующего изменения обновить обе суммы после чтения актуального опубликованного сайта.

Этот коммит подготавливает новую загрузку. Пока FTP-настройки для app.liniyasporta.ru не добавлены, проверка подключения остановит workflow до любых удалённых изменений.
